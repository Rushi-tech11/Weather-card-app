# 🌦 Weather Card App

A modern and responsive weather application built using HTML, CSS, and JavaScript.  
This application fetches real-time weather data using a Weather API and displays weather conditions based on the searched city.

# 📌 Features

✅ Real-time weather updates  
✅ Search weather by city name  
✅ Responsive design for all devices  
✅ Dynamic weather icons  
✅ Clean and modern UI  
✅ API integration using JavaScript  
✅ Fast and lightweight application
